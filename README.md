# ScholarGrid

A school student portfolio and Excel registry interface built with React, TypeScript, and Vite.

## Run locally

Prerequisites: Node.js

1. Install dependencies with npm install.
2. Put a Gemini API key in .env.local.
3. Start the app with npm run dev.

## Demo data and privacy

The bundled roster contains fictional demonstration records only. It does not include real student contacts, dates of birth, or student photographs. Keep identifiable student records, contact details, and photos out of source control. Local environment files are ignored by Git; .env.example is the safe configuration template.
